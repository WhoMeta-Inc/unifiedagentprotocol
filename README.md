# Unified Agent Protocol – Core SDK (uap-core)

`uap-core` is the reference Python implementation of the **Unified Agent Protocol (UAP)** – an extensible standard for describing AI agents, tools, triggers, and execution bridges in a platform-agnostic way.

```
pip install uap-core
```

## Features (Milestone 1)
* Parse tool definitions from OpenWebUI JSON, LangChain, and OpenAPI specs.
* Strongly-typed `pydantic` models (`Agent`, `Tool`, `Trigger`, …).
* Export helpers to A2A, MCP, and OpenAPI v3.
* Zero-dependency CLI: `uap bind --input tools.json --format mcp`.

## Project Status
Early alpha. The public API may change without notice.
