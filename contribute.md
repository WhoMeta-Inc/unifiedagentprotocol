# Contributing to United Agent Protocol (UAP)

First of all, thanks for taking the time to contribute!

We welcome contributions to the United Agent Protocol (UAP) project. Please take a moment to review this document to make the process smooth and consistent.

---

## 🧭 What to Contribute

- Bug fixes
- New protocol extensions
- Language bindings (Python, .NET, etc.)
- Adapter templates for other AI agent frameworks
- Improvements to the documentation
- Use case examples and sample integrations

---

## 🛠 Development Setup

1. Fork this repository
2. Clone your fork
3. Create a new branch: `feature/your-description`
4. Make your changes and commit with meaningful messages
5. Push to your fork and submit a Pull Request (PR)

We recommend following [Conventional Commits](https://www.conventionalcommits.org/) for clarity and better changelog automation.

---

## 🧪 Tests

Please write tests for any code you contribute. If unsure how, open an issue and we’ll help.

---
